# JalDrishti MVP demo script

1. Select **Illustrative Demo Watershed** and state that all records are prepared demo data.
2. Show the intervention point and explain the layer's source/status label.
3. Submit an approved demo image; show available metadata and its map placement.
4. Explain each GeoProof component rather than presenting only a score.
5. Compare prepared satellite indicators only after showing source, date, method, and caveats.
6. Show the risk and recommendation rationale, including exclusions and uncertainty.
7. Close: “This pilot connects evidence, measurement, and prioritisation. Its production phase requires validated sources, calibrated rules, and operational controls.”

Never claim that the MVP proves causality, prevents fraud, or offers universal model accuracy.
